# Pagerless 1.0.1

Pagerless 1.0.1 is a presentation patch on the 1.0.0 investigation service. The API,
chart values, RBAC and draft-pull-request contract are unchanged.

- **Dashboard answers render as Markdown.** Headings, lists, bold text, inline code and
  tables are parsed into React elements. Raw HTML is skipped and links are restricted to
  explicit safe schemes, so an answer still cannot inject markup.
- **`kubectl page` is colour-aware.** Tool calls, statuses, headings, inline code and
  citations are styled on a terminal, and a unified diff is green/red with a cyan hunk
  header. Pipes, redirects, `NO_COLOR` and `TERM=dumb` keep the exact plain output.
- **The recordings and README were refreshed** against the published chart, including the
  formatted dashboard answer and the coloured terminal transcript.

## Install

```sh
helm install pagerless oci://ghcr.io/a-hagi613/pagerless/core/charts/pagerless \
  --version 1.0.1 --namespace pagerless --create-namespace
```

If the GHCR chart is not anonymously readable yet, install the same chart from this
GitHub Release:

```sh
helm install pagerless \
  https://github.com/a-hagi613/pagerless/releases/download/pagerless-v1.0.1/pagerless-1.0.1.tgz \
  --namespace pagerless --create-namespace
```

## Images

- `ghcr.io/a-hagi613/pagerless/core/server:1.0.1`
- `ghcr.io/a-hagi613/pagerless/core/agent:1.0.1`

Both are multi-arch images for `linux/amd64` and `linux/arm64`. The chart defaults to
these coordinates. The `1.0.0` artifacts remain immutable and are not rewritten.
