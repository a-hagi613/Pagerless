# Pagerless 1.0.0

Pagerless 1.0 is a read-only Kubernetes investigation service. Ask a question
in the dashboard or with `kubectl page`, follow the ordered evidence trail, and
review a proposed fix as a draft pull request. A human merges every change.

This is the fresh 1.0 distribution at the immutable tag `pagerless-v1.0.0`. It
is not the retired v1.0.0 operator; those legacy tags and artifacts stay frozen.

## One install

The chart, the `pagerless-server` and `pagerless-agent` images, and the
`kubectl page` plugin are released at one version.

```sh
helm install pagerless oci://ghcr.io/a-hagi613/pagerless/core/charts/pagerless \
  --version 1.0.0 --namespace pagerless --create-namespace
```

If the GHCR chart is not anonymously readable yet, install the same chart from
this GitHub Release:

```sh
helm install pagerless \
  https://github.com/a-hagi613/pagerless/releases/download/pagerless-v1.0.0/pagerless-1.0.0.tgz \
  --namespace pagerless --create-namespace
```

The chart references an existing credentials Secret. Supply an
OpenAI-compatible model endpoint, a source repository, and read-only cluster
access; `values.yaml` names every key the Secret must carry. Readiness names
any unmet prerequisite.

## Images

- `ghcr.io/a-hagi613/pagerless/core/server:1.0.0`
- `ghcr.io/a-hagi613/pagerless/core/agent:1.0.0`

Both are multi-arch images for `linux/amd64` and `linux/arm64`. The chart
defaults to these coordinates.

## CLI

The release carries four `kubectl-page` archives for Linux and macOS on amd64
and arm64, `checksums.txt`, one SBOM per archive, and the rendered `page.yaml`
Krew manifest.

```sh
curl -fsSLO https://github.com/a-hagi613/pagerless/releases/download/pagerless-v1.0.0/checksums.txt
curl -fsSLO https://github.com/a-hagi613/pagerless/releases/download/pagerless-v1.0.0/kubectl-page_1.0.0_linux_amd64.tar.gz
sha256sum --check --ignore-missing checksums.txt
tar -xzf kubectl-page_1.0.0_linux_amd64.tar.gz
install -m 0755 kubectl-page ~/.local/bin/kubectl-page
```

Or install the Krew manifest attached to the release:

```sh
kubectl krew install --manifest=https://github.com/a-hagi613/pagerless/releases/download/pagerless-v1.0.0/page.yaml
```

The chart tarball has its own checksum beside it as
`pagerless-1.0.0.tgz.sha256`.

## Verification

The publish job installs the linux/amd64 archive and the Krew manifest from the
fresh GitHub Release, checks every archive against `checksums.txt`, and then
checks anonymous access to the release, both images, and the chart. The
release tag and every distribution coordinate are immutable: a failed or
partial publication is replaced by a new version, never by rewriting this one.
