# Issue Triage Labels

The engineering skills refer to five canonical issue triage roles. This file maps each role to the label used in this repository's GitHub Issues.

Issue triage is unrelated to the Triage domain concept defined in [`GLOSSARY.md`](../../GLOSSARY.md).

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a role, apply the corresponding label from this table.
